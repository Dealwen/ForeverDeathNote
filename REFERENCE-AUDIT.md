# Полевой журнал Forever Death Note

Разбор 11 пользовательских референсов для WoW Forever. Номера соответствуют порядку приложенных изображений.

| Скриншот | Что видно | Как решение применяется в Forever Death Note |
| --- | --- | --- |
| 1. Social Diary, обложка | Один переплёт объединяет историю, карту и карточку персонажа. | Тёмный переплёт и иллюстрации принадлежат FDN. Пергамент отделяет записи от карточки боя. |
| 2. Social Diary, хронология | День и время читаются по левому краю. Тип события выделен иконкой. | События отсортированы по времени. Дата открывает группу, у каждого боя видны противник, зона и исход. Поиск проверяет имя и зону. |
| 3. Social Diary, карта встреч | Карта открывается в контексте одного человека. Есть выход к общему просмотру. | «Карта» у обидчика и в досье показывает его встречи и последнюю зону с координатами. «Все встречи» возвращает общий вид. |
| 4. Social Diary, личная летопись | События, заметки и география читаются как разные уровни одной истории. | История и личная заметка доступны в досье. Из записи можно открыть разбор боя и карту при известных координатах. |
| 5. Social Diary, недавние игроки | Компактный список с портретами, именами и отдельным действием для записи. | Список «Рядом» даёт доступ к противнику, досье и доступному в клиенте действию с целью. |
| 6. DungeonJournal, каталог | Сетка иллюстрированных карточек. Поиск и избранное отделены от содержимого. | Боевой атлас использует карты зон WoW, поиск, избранное и фильтры по континентам. Для зон без привязки к двум континентам есть отдельный раздел. |
| 7. DungeonJournal, подробности | Выбранная строка остаётся видимой рядом с карточкой. | Карточка боя, игрока или гильдии открывается рядом с выбранной строкой. Из карты территории можно вернуться к прежнему поиску и фильтрам атласа. |
| 8. DungeonJournal, RPG Mode | Каталог показывает прогресс и местами иллюстрации вместо раскрытых данных. | Прогресс читается в ладдере и недельных целях. Карточки зон показывают реальный счёт, при отсутствии карты используется условная иллюстрация. |
| 9. Overlord, обзор | Широкая полоса показывает соотношение двух фракций. | В рейтингах виден счёт за 30 дней, на «Фронте недели» отдельная полоса строится по выбранному недельному источнику. |
| 10. Overlord, следующая цель | Иллюстрация, одна цель и список зон, активных за последние пять минут. | «Охота» выделяет текущую цель и последние встречи. Во «Фронте недели» можно переключиться с горячих зон недели на зоны, где бой прошёл за последние пять минут, и посмотреть время последней записи. |
| 11. Overlord, таблицы | Плотные рейтинги игроков, гильдий и игровых объектов. Цвет помогает различить фракции. | Вкладки отделяют игроков, гильдии и классы. Счёт фракций, топ‑3 гильдии, звания и конкретные бои остаются доступными для проверки. |

## Визуальные роли

| Роль | Решение |
| --- | --- |
| Переплёт | Тёплый угольный фон, медная рамка. |
| Бумага | Оригинальная кремовая текстура для личных записей. |
| Чернила | Коричневый текст на бумаге, бордовый для смерти и оливковый для добивания. |
| Основное действие | Медно-бордовая кнопка и светлый текст. |
| Фракции | Красная и синяя части шкалы с явными числовыми подписями. |
| Арт | Игровые карты через API клиента и оригинальная текстура бумаги. |

Материалы авторов аддонов: [Social Diary](https://www.curseforge.com/wow/addons/social-diary), [DungeonJournal](https://www.curseforge.com/wow/addons/dungeonjournal) и [Overlord Forever](https://www.curseforge.com/wow/addons/overlord-forever).
