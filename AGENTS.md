# Forever Death Note

The canonical GitHub repository for this add-on is `https://github.com/Dealwen/ForeverDeathNote`, branch `main`.

For every completed add-on update, commit the related add-on changes and publish the commit to `main`. If local Git push is unavailable, use the GitHub connector. Check the current branch head before publishing and verify the resulting commit on GitHub.

Keep website code, other add-ons, release archives, credentials, and in-game SavedVariables out of this repository.
